# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:
- Be kind.
- Assume good intent.
- Give feedback on the work, not the person.
- Animators, developers and first-time contributors are equally welcome.

To report unacceptable behaviour, email **konkomaji@gmail.com**. Reports are handled confidentially.
